### Объекты и места
`Тип`
- `Объект`
	- `Отдел`
	- `Процесс`
	- `Контейнер`
		- `Тип контейнера`
			- `Запрос`
			- `Результат`
	- `Показатель`
	- `Линия связи`
- `Место`
	- `Тип места`
		- `Свободное` - Доступно для размещения `Объект`
		- `Занятое` - Занято `Объект`
### Команды
- `Создал`
- `Установил координаты`
- `Поместил в` /// `Родитель` может быть максимум один
- `Отвязал родителя`
- `Установил значение`
- `Связал показатели`
- `Скопировал показатели контейнера` /// Только `ID`, `Значение` = 0
- `Отменил`

### Функции
#### Определил `Тип места`
1. Определил размер `Место`
2. Определил `Место`, которое займёт `Объект` после `Установил координаты` пересекается с другим `Объект`?
	Да - `Место` `Тип места` `Занятое` `Объект`
	Нет - `Место` `Тип места` `Свободное`

Можно выбрать несколько Процессов и Отделов при помощи`Selection Box` и переместить на свободное место.
При нажатии на пустое место состояние `Selected` сбрасывается.
