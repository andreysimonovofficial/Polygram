
Есть функция `Поместил в` `Отдел` `Процесс` и `Поместил в` `Отдел` `Отдел`. У Них есть единое модальное окно "Поместить `Объект` в `Объект`". При этом поместить `Процесс` в `Процесс` и `Отдел` в `Процесс` запрещено.
# Тело модального окна Поместить Объект в Объект

## 1. Параметры окна и данные шапки для данного сценария

* **Размеры окна:** ширина `540 px` (`max-width: 540 px`), высота `201 px` (строго по макету, без растягивания по экрану).

* **Подписи шапки:**

  * Заголовок: `Поместить {Имя Объекта #1} #{ID Объекта #1} в {Имя Объекта #2} #{ID Объекта #2}?` (`Inter`, `16 px`, полужирный `600`, высота строки `22 px`, цвет `#FFFFFF`, визуально соответствующий эталону по толщине штриха и межбуквенному интервалу без разреженности).

  * Подзаголовок: текстовая строка `{Имя Объекта #2} #{ID Объекта #2}` (`Inter`, `11 px`, жирный `700`, высота строки `13 px`, межбуквенный интервал `0.44 px`, цвет `#A1A1AA`) без иконки.

## 2. Тело модального окна

* **Отступы секции:** сверху `4 px`, слева `20 px`, справа `20 px`, снизу `16 px`.

* **Информационная плашка объекта:** размер `498×34 px` (растягивается по ширине внутренней области, высота `34 px`), базовый фон `#252525`, рамка `1 px` `#373839`, скругление `2 px`, горизонтальные отступы `10 px`, зазор между элементами `8 px`. Все элементы строки внутри плашки должны быть выровнены **строго по вертикальному центру** относительно её внутренней области, без смещения вниз или проседания к нижнему краю:

  * Иконка объекта: размер `16×16 px`, цвет `#FFFFFF`.

  * Название объекта (`{Имя Объекта #1}`): растягивается по доступной ширине (`flex-grow: 1`), `Inter`, `14 px`, средний вес (`500`), высота строки `17 px`, цвет `#FFFFFF`, горизонтальный скролл при переполнении как в макете.

  * Идентификатор объекта (`#{ID Объекта #1}`): `Inter`, `14 px`, средний вес (`500`), высота строки `17 px`, цвет `#A1A1AA`, выравнивание по вертикальному центру.

## 3. Логика кнопки «Готово» для данного сценария

* **Нажатие `Готово`:** выполняет операцию размещения/добавления объекта `{Имя Объекта #1}` (`#{ID Объекта #1}`) в целевой объект `{Имя Объекта #2}` (`#{ID Объекта #2}`), сбрасывает состояние окна и закрывает его.
