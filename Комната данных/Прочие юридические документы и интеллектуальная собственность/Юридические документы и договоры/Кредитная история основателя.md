# Кредитная история основателя — Polygram

## Проблема
Основатель Андрей Симонов: личные средства исчерпаны, кредитная история плохая, есть задолженность ориентировочно $5000.

## Решение — пошаговый план
1. Нанять юриста по кредитным вопросам. Ориентировочная стоимость: $300.
2. Погасить долги основателя. Ориентировочная сумма: $5000.
3. После погашения — выстроить историю timely платежей, закрыть текущие обязательства.
