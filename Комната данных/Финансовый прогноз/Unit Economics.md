# Unit Economics

## LTV (Лifetime Value)
- [x] LTV: $720 (средний чек $20/мес × 36 месяцев)
- [x] Период расчёта: 3 года

## CAC (Customer Acquisition Cost)
- [x] CAC: $150 (маркетинг и продажи на одного платящего пользователя)
- [x] Период расчёта: год 1

## Маржинальность
- [x] Маржинальность: 50% (валовая прибыль к выручке, год 1 по финмодели)
- [x] Период расчёта: год 1

## Соотношение LTV/CAC
- [x] LTV/CAC: 4.8

## Примечание
Данные взяты из Финмодели Polygram. Требуется подтвердить у основателя или финансового агента перед отправкой инвесторам.
