# Статус MVP и план выпуска — Polygram

## Текущее состояние
- Фронтенд: красивый, готов ориентировочно на 80%
- Бэкенд: не сделан
- Аутентификация: не уточнено
- Статус: прототип / идея

## План завершения MVP
1. Доделать фронтенд — ориентировочно 1 неделя
2. Выпустить фронтенд в качестве релиза
3. Сделать бэкенд
4. Снять видео о продукте
5. Начать продажи (предзаказ)

## Общий срок
- Ориентировочно 1 месяц до готового MVP

## Ограничения
- «Узкий» MVP с ограниченным функционалом запустить нельзя
- Минимальная функция, приносящие деньги уже сейчас — отсутствует
- Продажу до полного MVP можно организовать через предзаказ

## Первые платящие клиенты
- Кто именно — не определено
- Требуется мозговой штурм с Директором по Маркетингу и Директором по Продажам
- Кандидаты: основатели стартапов, ИИ-агентства, малый бизнес (гипотеза)
