База показателей представляет собой список, в котором показатели в реальном времени, значения которых подтягиваются из API различных сервисов. Например счёт Monobank, просмотры YouTube, посещения сайта из Google Analytics.

Заголовки - название сервиса, в них строки - список всех показатели, которые доступны для отслеживания.
