# Тело модального окна добавления показателя (специфическая часть)

## 1. Параметры окна и данные шапки для данного сценария

* **Размеры окна:** ширина `540 px`, высота `197 px` (строго по макету, без растягивания по экрану).

* **Единая раскладка:** сохраняется одинаковой для всех типов показателей из цепочки (`Число → Время → Дата → Дедлайн → Процент → Бинарный → Длительность → Деньги → Текст → Формула → Метка времени → Число`).

* **Подписи шапки:**

  * Заголовок: `{Имя Процесса}` (`Inter`, `16 px`, полужирный `600`, высота строки `22 px`, цвет `#FFFFFF`, визуально соответствующий эталону по толщине штриха и межбуквенному интервалу без разреженности).

  * Подзаголовок: `Добавить Показатель в {ТИП КОНТЕЙНЕРА}` (`Inter`, `11 px`, жирный `700`, высота строки `13 px`, межбуквенный интервал `0.44 px`, цвет `#A1A1AA`). Фраза `Добавить Показатель в ` выводится в исходном написании без принудительного верхнего регистра, а значение `{ТИП КОНТЕЙНЕРА}` сохраняет свой формат (например, `ЗАПРОС`).

## 2. Тело модального окна

* **Отступы секции:** сверху `4 px`, слева `20 px`, справа `20 px`, снизу `16 px`.

* **Внутренняя рамка:** размер `498×52 px`, фон `#222222`, рамка `1 px` `#373839`, скругление `4 px`, внутренний отступ `8 px`, горизонтальный зазор между элементами `8 px`. Все элементы строки внутри внутренней рамки должны быть выровнены **строго по вертикальному центру** относительно её внутренней области, без смещения вниз или проседания к нижнему краю.

* **Кнопка смены типа показателя:**

  * Вёрстка: размер `34×34 px`, базовый фон `#252525`, рамка `1 px` `#373839`, скругление `4 px`, иконка `16×16 px` белого цвета (`#FFFFFF`) согласно типу показателя:

    * `Время` → иконка часов

    * `Дата` → иконка календаря

    * `Дедлайн` → иконка календаря с часами

    * `Процент` → иконка процента

    * `Бинарный` → иконка переключателя

    * `Длительность` → иконка часов

    * `Деньги` → иконка валюты/доллара

    * `Текст` → иконка документа/текста

    * `Формула` → иконка калькулятора

    * `Метка времени` → иконка календаря с часами

    * Прочие (включая `Число`) → иконка решётки (`#`)

  * Состояния: наведение (`hover`) — фон `#2B2B2B`; нажатие (`active`) — фон `#323232`.

  * Поведение при клике: переключает тип показателя на следующий по цепочке (`Число → Время → Дата → Дедлайн → Процент → Бинарный → Длительность → Деньги → Текст → Формула → Метка времени → Число`), очищает поле значения, дату и время, а также закрывает выпадающий календарь.

* **Поле ввода имени показателя:**

  * Вёрстка: растягивается по ширине, высота `34 px`, базовый фон `#252525`, рамка `1 px` `#373839`, скругление `2 px`, отступы `7.5 px` сверху/снизу и `10 px` слева/справа; текст и плейсхолдер `Inter`, `14 px`, средний вес (`500`), высота строки `17 px`, `#FFFFFF`, горизонтальный скролл при переполнении как в макете.

  * Плейсхолдер: `Имя Показателя`.

  * Состояния: наведение / нажатие (`hover / active`) — фон `#282828`, рамка `1 px` `#4A4A4D`.

* **Составной блок (значение + синхронизация):** общий размер `130×34 px`, фон `#252525`, рамка `1 px` `#373839`, скругление `2 px`. Является единым контейнером-ограничителем для вложенных элементов: оба дочерних элемента должны располагаться строго внутри границ и контура блока без смещения вправо или вниз за пределы его рамки и стыковаться вплотную по горизонтали без лишних зазоров или выступающих внешних отступов:

  * Поле ввода значения: ширина `96 px`, высота `32 px`, отступы `7.5 px` сверху/снизу и `8 px` слева/справа, выравнивание текста по правому краю, `Inter`, `14 px`, средний вес (`500`), высота строки `17 px`, `#FFFFFF`, горизонтальный скролл при переполнении как в макете; плейсхолдер: `Значение`; наведение / нажатие (`hover / active`) — фон `#282828`.

  * Кнопка синхронизации: ширина `32 px`, высота `32 px`, базовый фон `#2B2B2B`, левая граница `1 px` `#373839` (проходит ровно по границе между элементами внутри контура блока), иконка синхронизации календаря (`15×15 px`), цвет `#A1A1AA`; наведение (`hover`) — фон `#323232`, нажатие (`active`) — фон `#383838`. Является визуальной заглушкой — обработчик клика отсутствует, при нажатии ничего не происходит.

* **Поле ввода единицы измерения:** ширина `88 px`, высота `34 px`, базовый фон `#252525`, рамка `1 px` `#373839`, скругление `2 px`, отступы `7.5 px` сверху/снизу и `10 px` слева/справа, выравнивание текста по правому краю, `Inter`, `14 px`, средний вес (`500`), высота строки `17 px`, `#FFFFFF`, горизонтальный скролл при переполнении как в макете; плейсхолдер: `Ед.`; наведение / нажатие (`hover / active`) — фон `#282828`, рамка `1 px` `#4A4A4D`.

## 3. Логика кнопки «Готово» для данного сценария

* Если имя показателя пустое (после удаления пробелов по краям): сбрасывает состояние формы добавления показателя и закрывает окно без сохранения.

* Если имя показателя не пустое:

  1. Разбирает введённое значение в формат значения показателя согласно выбранному типу показателя. При любой ошибке разбора возвращается значение `Значение Показателя – Null` (ошибки разбора пользователю не выводятся и сохранение не блокируют).

  2. Формирует целевое значение или требование в зависимости от направления (`Запрос` / `Результат`), где при ошибке разбора значение остаётся `Значение Показателя – Null`.

  3. Если показатель с таким же именем и таким же типом уже существует — добавляет новую запись для существующего определения показателя.

  4. Иначе создаёт новое определение показателя и добавляет запись для него.

  5. Сбрасывает состояние формы добавления показателя и закрывает окно.
