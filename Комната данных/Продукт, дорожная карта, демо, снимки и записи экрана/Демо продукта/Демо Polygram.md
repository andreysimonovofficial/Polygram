# Демо продукта Polygram (Pre-Seed)

## Описание
Визуальный графовый редактор для оркестрации ИИ-корпораций. Демо доступно по ссылке: https://polygram.id

## Основные возможности демо
- Создание холста с узлами-ИИ агентами
- Линии связи между агентами (контекстные меню, модальные окна)
- Организация агентов в отделы и процессы
- Контейнеры и объекты на холсте
- База показателей и метрик в реальном времени
- Горячие клавиши и UX/UI навигация
