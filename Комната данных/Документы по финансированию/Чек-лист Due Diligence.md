# Чек-лист подготовки к Due Diligence — Polygram

## Корпоративные документы
- [ ] Устав подписан и заверен основателем
- [ ] Регистрационные документы ФЛП 3 Група Украина (копии)
- [ ] Таблица капитализации (Cap Table) подписана
- [ ] Решения совета директоров (если будут приниматься)

## Документы по финансированию
- [ ] SAFE соглашение (шаблон готов, требует подписи инвестора)
- [ ] Конвертируемый заем (альтернатива, шаблон готов)
- [ ] Условия выкупа доли (описаны, не рекомендуются к использованию)
- [ ] Заявка на получение инвестиций

## Финансовые документы
- [ ] Финансовая модель (Finмодель)
- [ ] Unit Economics
- [ ] Market Sizing
- [ ] Оценка компании ($5 000 000 pre-money)
- [ ] Расходы и Runway ($100/мес на модели)

## Правовые документы
- [ ] IP Assignment (передача интеллектуальной собственности компании)
- [ ] Товарные знаки (если зарегистрированы)
- [ ] ToS / Privacy Policy
- [ ] Договоры с подрядчиками и сотрудниками

## Презентация для инвесторов
- [ ] Питч дек (содержимое определено)
- [ ] Мемо для Y Combinator (готово)
- [ ] Демо продукта

## Кредитная история основателя
- [ ] Нанять юриста по кредитам (~$300)
- [ ] Погасить долги (~$5000)
- [ ] Выстроить историю timely платежей
