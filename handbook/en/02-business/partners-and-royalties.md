## Licensing royalty model

Automated responsibility diversification and background partnership system.

Downloading repositories from GitHub and if they are useful — turning them into Polygram extensions. That is — when that application or code We monetize in Polygram — We pay royalties to the developers of that repository by license. Thus concentration goes to key Polygram functionality, and additional functions are delegated to partners.

Royalties to authors of third-party GitHub repositories for their integration as monetizable extensions.
