# Core Extensions

**Language:** **English** | [Русский](../ru/03-reference/core-extensions.md)

## Standard module specifications

### "Secretary"

Autonomous communication agent that follows up on leads, schedules meetings, and works non-stop via Telegram/email even with a closed browser, and all messages are always saved to a local database.

### "Finance"

Direct integration with acquiring/banks for displaying real financial flow indicators directly on canvas blocks and showing transactions.

### "Contracts" (CONTRACT.md)

Long-term tasks with checks and automatic reminders via Secretary.
