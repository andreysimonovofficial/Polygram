# Building AI-Corporation

**Language:** **English** | [Русский](../ru/02-guides/building-ai-corp.md)

## Department assembly scenario

The user assembles a clear visual map that immediately becomes a real living system with agents and automations. Result — reduced fragmentation, increased efficiency, full automation.

Each Process and Department has its own chat.

In the chat you can communicate with the Agent of this Process/Department. At the same time, the Department chat is a dialog with Its Supervisor-Orchestrator. Such an Agent manages and controls the work of nested Processes and Departments in His Department.

## Example scenario

A Process has Request "Technical Specification" and output "Product for review". Then the Agent waits for the technical specification file from another Process (that is, data is transmitted between processes along connection lines), and having received it, performs the task ASAP, reporting and demonstrating a log in the chat, and when ready, He sends "Product for review" to the next Agent in the QA process. And when a bottleneck appears (for example, frequent interferences in some Process), the Supervisor-Orchestrator of the Department eliminates them. This is an AI-Corporation.

The system is not limited to only this scenario. Since Polygram is a constructor of AI-Corporations. There is not only development there. Everything is universal.

## Request/Result setup

A Process is the Source of Its Goals and the Goal of Its Sources. Request is an input container, which lists everything the Process needs to work. Result is an output container, which lists everything the Process produces.

## Delegation to Supervisor-Orchestrator

The Department chat is a dialog with Its Supervisor-Orchestrator. The Supervisor manages and controls the work of nested Processes and Departments in His Department, eliminates bottlenecks and interferences.

## Bottleneck elimination

Bottlenecks are highlighted automatically on the canvas. The user sees them through statuses in the Process itself (block), where there is a request and result and their statuses. The Supervisor-Orchestrator of the Department eliminates interferences in processes.
