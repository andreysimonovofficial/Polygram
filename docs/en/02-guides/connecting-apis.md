# Connecting APIs

**Language:** **English** | [Русский](../ru/02-guides/connecting-apis.md)

## Turning external applications into extensions via API

We turn applications from the internet into extensions for Polygram. Since Polygram is also visualization of API and calculations, and practically any application uses an API.

Data is transmitted instantly. Thanks to the suitable "engine", everything goes at the speed of a trading terminal.

## Multi-agent network orchestration and complex API system monitoring

Polygram allows orchestrating multi-agent networks and monitoring complex API systems. Any external application that uses an API can be turned into a Polygram extension, making it part of the visual corporation graph.
