# 0005. Ортогональные линии
**Дата:** 2026-11-05 · **Решил:** основатель (стиль) + тех. сооснователь (алгоритм)

**Решение.** Линия «горизонталь → вертикаль → горизонталь» по каналу в зазоре между колонками;
в колонке три дорожки, чтобы линии не слипались. Обратные связи обходят сверху или снизу
(5 отрезков). Канал выбирается так, чтобы линия не шла сквозь чужие карточки.
**Ограничения v0.** Нет полного обхода препятствий (как у конвейеров Factorio): в плотных
раскладках длинная линия может пройти по карточке. При перемещении объекта пересчитываются
только его связи (`reroute_all` — полный пересчёт).
**Дальше.** Этап 9+: обход препятствий (A*), инкрементально.
