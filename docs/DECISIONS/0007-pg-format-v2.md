# 0007. Формат .pg v2
**Дата:** 2026-11-05 · **Решил:** основатель

**Решение.** Новый формат `polygram/2`; старые файлы не открываются (с понятным сообщением).
В файле только исходное: структура, значения, клетки. Статусы, потоки и линии пересчитываются.
**На будущее (этап 8).** Импорт `.pg` как Отдела требует манифеста разрешений: коннекторы
не получают доступ к деньгам, публикациям и технике без явного подтверждения человека;
секреты в файле не хранятся.
