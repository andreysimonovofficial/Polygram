# 0010. Линии связей — визуальный слой холста
**Дата:** 2026-11-14 · **Заменяет:** 0005

**Решение.** Линия связи не хранится в ядре и не попадает в API и MCP. Её строит холст
(`crates/canvas/src/routing/`) по положению карточек. Ядро отдаёт только карточки и список
связей «откуда → куда». Удалены: `route.rs`, дорожки и очередь пересчёта в `layout.rs`,
`EdgeGeom.points`, события `edge_routed` и `routes_changed`, команда `reroute_all`.

**Правила линии (ТЗ «Линии связи»).**
1. Первый и последний отрезки строго горизонтальны. Из правой точки строки показателя линия
   идёт только вправо, из левой — только влево; в правую точку входит справа налево, в левую —
   слева направо.
2. Первый и последний отрезки заканчиваются на вертикали сетки вне карточки, не ближе двух
   клеток от её края.
3. Дальше линия идёт по горизонталям и вертикалям сетки по самому короткому пути в обход
   карточек. Если конец первого отрезка и начало последнего на одной вертикали — между ними
   один вертикальный отрезок («Z»); если порты на одной высоте — прямая.
4. Нет петель, нет разворотов, нет обходов длиннее кратчайшего пути, нет лишних колен.

**Как выбирается путь.** Среди всех путей берётся самый короткий; из равных — с наименьшим
числом колен; из равных — ближайший к середине между карточками и с «естественными» портами
(выход справа, вход слева). Сторону порта (левую или правую) на каждом конце выбирает сам
поиск. Карточки — препятствия; отделы-рамки — нет.

**Воздух вокруг карточек.** Сначала путь ищется с охранной зоной в одну клетку вокруг
карточек. Если так пути нет — линия может идти вплотную к карточке; затем допускается первый
или последний отрезок в одну клетку; в крайнем случае (карточка зажата со всех сторон)
рисуется простая ломаная без обхода. Что получилось, видно по `Route::quality`.

**Зазор между колонками автораскладки — 4 клетки** (было 3): две клетки на выход, две на
вход, и обе вертикали совпадают. При меньшем зазоре линия получает обратную «ступеньку».

**Производительность.** Прямые варианты считаются без поиска. Поиск — A* по «сжатой» сетке
(вершины только на значимых линиях), 300 объектов и 699 связей — около 0,5 с на все линии.
Маршрут кэшируется и пересчитывается, только если изменились его концы или карточки в его
области влияния (любой путь не длиннее найденного целиком лежит внутри неё). Считаются только
линии, попавшие в видимую область.

**Ограничения.** Линии разных связей могут идти по одной линии сетки (дорожек нет): на
коротком зазоре они сливаются. Проверка кратчайшести — сравнение с независимым перебором на
случайных сценах (`routing/tests.rs`).
