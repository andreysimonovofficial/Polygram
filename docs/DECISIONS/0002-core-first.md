# 0002. Ядро отдельно от окна; всё через команды
**Дата:** 2026-11-05 · **Решил:** основатель (схема) + тех. сооснователь

**Решение.** Вычисления живут в `core` и работают без окна. Человек, агент и внешний мир
равноправно шлют `Command`; в ответ — результат и события с номером ревизии.
**Почему.** MCP и API первичны (дата-центры, агенты в фоне); окно лишь показывает.
**Следствия.** Тесты и бенчмарки идут без окна; «статусы по запросу» отменены — статусы
всегда актуальны, по запросу упаковывается только текст/JSON.
