# 0003. Три хранилища
**Дата:** 2026-11-05 · **Решил:** основатель (схема)

**Решение.** Иерархия (структура), Значения и статусы, Архитектура графа (клетки и линии) —
три отдельных блока данных с разной скоростью изменения и разными читателями.
**Почему.** Окну и агентам нужны разные срезы; быстро меняющиеся числа копируются дёшево,
редко меняющаяся геометрия публикуется только при изменении.
