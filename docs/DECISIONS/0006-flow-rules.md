# 0006. Правила потоков и статусов — из MVP без изменений
**Дата:** 2026-11-05 · **Решил:** тех. сооснователь

**Решение.** Спрос выхода = сумма требований подключённых входов. Поставка по связи =
требование × min(1, значение / спрос). Лимит выхода = сумма лимитов подключённых входов
(если заданы у всех), иначе собственный. Статусы — 8 кодов MCP (`ok, warning, deficit,
surplus, unconnected, invalid, disabled, unknown`); 5 «внутренних» статусов окна MVP упразднены.
**Новое.** Расчёт инкрементальный: пересчитываются только затронутые показатели.
Корректность охраняется тестом «инкрементальный = полный пересчёт» на случайных операциях.
