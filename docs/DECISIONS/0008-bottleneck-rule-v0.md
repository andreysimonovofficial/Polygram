# 0008. Правило «узкого места» v0
**Дата:** 2026-11-05 · **Решил:** тех. сооснователь — **ТРЕБУЕТ УТОЧНЕНИЯ основателем**

**Решение (временное).** Узкое место — выход в статусе «дефицит». Важность = недостача
(спрос − значение); при равенстве — больше потребителей; затем меньший индекс.
**Почему временное.** Настоящее узкое место зависит от цепочки (что блокирует больше всего
потомков), а не только от одного выхода. Сформулируем правило вместе, когда увидим граф в окне.
