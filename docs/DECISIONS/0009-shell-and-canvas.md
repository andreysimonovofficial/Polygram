# 0009. Оболочка egui + отдельный GPU-холст; тема — данные
**Дата:** 2026-11-05 · **Решил:** основатель (вариант A)

**Решение.** egui остаётся тонкой оболочкой (окна, ввод); холст рисуется отдельным проходом
wgpu пачками прямоугольников с уровнями детализации. Меню правой кнопки — позже.
Цвета, символы, форма линий и скругления — данные темы, а не код. Сейчас одна тема —
терминальная: чёрный фон, рамки 1 px без скруглений, один моноширинный шрифт, цвет только
для статуса.
**Состояние.** Решение принято, реализация — шаг 2.
