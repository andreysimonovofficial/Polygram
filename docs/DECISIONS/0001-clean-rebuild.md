# 0001. Чистовик вместо правки MVP
**Дата:** 2026-11-05 · **Решил:** основатель

**Решение.** Собираем новое приложение с нуля, а не правим прототип.
**Почему.** Меняются сразу сетка, рендеринг, хранение данных и место вычислений; правка
прототипа «буксовала» бы. Прототип был ценен знаниями (правила расчёта, формат статусов) —
они перенесены, код — нет.
**Что отвергли.** Постепенная миграция `app.rs` (5 900 строк, всё переплетено).
**Пересмотреть, если:** перенос коннекторов из MVP окажется дороже переписывания.
