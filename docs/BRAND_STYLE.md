# Firменный стиль: иконки

В приложении Polygram используются **только иконки Lucide** (через 크ейт `egui-lucide`).

## Правило

Любая новая или заменяемая иконка в интерфейсе берётся из набора Lucide SVG-иконок. Запрещено использовать:
- эмодзи (`🌐`, `⚠`, `🗑`, `⚙` и т. п.) как иконки интерфейса;
- символьные тексты (`◆`, `▶`, `◀`, `←`, `▼`) вместо иконок;
- иконки из других наборов (FontAwesome, Material, Phosphor и т. п.).

## Подключение

Иконки подключаются через `egui-lucide` в `crates/polygram`. При старте окна регистрируются загрузчики SVG `egui_extras::install_image_loaders(&ctx)`.

## Соответствие иконок (текущее)

| Место | Было | Стало (Lucide) |
|---|---|---|
| Статус привязки (OK) | `🌐` | `Globe` |
| Статус привязки (ошибка) | `⚠` | `AlertTriangle` |
| Настройки привязки | `⚙` | `Settings` |
| Удалить запись | `🗑` | `Trash2` |
| Назад | `←` | `ArrowLeft` |
| Раздел раскрыт/свернут | `▼` / `▶` | `ChevronDown` / `ChevronRight` |
| Символ потока запроса | `▶` | `ChevronRight` |
| Символ потока результата | `◀` | `ChevronLeft` |
| Символ объекта / раздела | `◆` | `Diamond` |

Размер, цвет и толщина 줄я задаются во время рендера через методы `size()`, `color()`, `stroke_width()` у `Lucide::*`.
