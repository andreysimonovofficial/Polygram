# ADR 0001: Изоляция ванильного ядра CAD

**Язык:** [English](../en/04-architecture/adr/0001-vanilla-cad-isolation.md) | **Русский**

## Статус

Accepted

## Контекст

При добавлении расширений в `/extensions` необходимо гарантировать, что чистый код ванильного CAD не изменится. Расширения объявляют инструменты и их команды, но никогда не влияют на ядро.

## Рассмотренные варианты

1. Разрешить расширениям модифицировать ядро CAD — отклонено, так как нарушает принцип модульности и стабильности.
2. Полная изоляция ядра от расширений — принято. Расширения хранятся в отдельных локальных репозиториях (`/extensions`) и взаимодействуют с ядром только через механизм команд.

## Решение

Ванильное ядро не меняется при добавлении расширений. Расширения объявляют инструменты и их команды. Мыш, клавиатура и MCP используют один механизм команд. Агент по MCP может делать `extension create` / `extension update`.

## Последствия

* Положительные: стабильность ядра, модульность, возможность безопасного добавления новых функций.
* Отрицательные: расширения не могут напрямую изменять внутреннюю логику ядра.
