# ADR 0002: Терминология Request/Result

**Язык:** [English](../en/04-architecture/adr/0002-request-result-terminology.md) | **Русский**

## Статус

Accepted

## Контекст

В коде и интерфейсе использовался термин In, который создавал путаницу у пользователей. Необходимо зафиксировать замену термина In на Request (Запрос) и удаление слова «Дефицит» из UI.

## Рассмотренные варианты

1. Оставить термин In — отклонено, так как вызывает путаницу.
2. Заменить In на Request (Запрос) и убрать «Дефицит» из UI — принято.

## Решение

Термин In полностью заменен на Request (Запрос). Статусы Запроса: Удовлетворён / Ожидание (слово «Дефицит» убрано из UI). Статусы Результата: Ожидание / Избыток. Главное правило: Если в Запросе Ожидание, Результат строго блокируется.

## Последствия

* Положительные: чёткая терминология,absence путаницы у пользователей.
* Отрицательные: необходимость обновления всех ссылок на термин In в коде и документации.
