# Протокол MCP

**Язык:** [English](../en/03-reference/mcp-protocol.md) | **Русский**

## Единый командный слой

Сам Polygram в своей основе — это чистый CAD с коннекторами API, MCP и т. д. Система модульная. Можно создавать абсолютно любые расширения. Всё максимально бесшовно подключается. Какие бы расширения Ты не подключал, всё равно это по факту просто передача данных. Запрос и результат. Всё просто. Polygram просто делает это всё визуально эргономичным и производит вычисления (Коэфициэнты, формулы и т. д.).

* Ядро CAD хранит граф, холст и официальные базовые действия.
* Расширения объявляют инструменты и их команды.
* Мыш, клавиатура и MCP используют один механизм команд.
* Панорамирование, выделение и связи становятся расширениями.
* Агент создаёт или обновляет расширение, после чего оно появляется на холсте.
* Ванильное ядро не меняется при добавлении расширений.

## Команды управления холстом и расширениями

MCP-сервер (JSON-RPC 2.0 поверх stdio) подключается к Claude Desktop, Open WebUI и другим MCP-клиентам. Инструменты:

* `execute_command` — выполнить команду Polygram;
* `get_snapshot` — последний снимок состояния;
* `get_objects` — список всех объектов;
* `get_stats` — статистика графа.

Агент по MCP может делать `extension create` / `extension update`. Тем самым делая те самые модули для CAD. Пользователь ощущает Себя реальным начальником. Полная автономия: Агент создает/обновляет extension и сразу подключает его к холсту без лишних вопросов.
