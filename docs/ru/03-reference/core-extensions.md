# Базовые расширения

**Язык:** [English](../en/03-reference/core-extensions.md) | **Русский**

## Спецификация штатных модулей

### «Секретарь»

Автономный агент коммуникации, который дожимает лиды, назначает встречи и работает бесперебойно через Telegram/почту даже при закрытом браузере, а все сообщения всегда сохраняются в локальную базу.

### «Финансы»

Прямая интеграция с эквайрингом/банками для вывода реальных показателей финансовых потоков прямо на блоки холста и отображения транзакций.

### «Контракты» (CONTRACT.md)

Долгосрочные задачи с проверками и автоматическими напоминаниями через Секретаря.
