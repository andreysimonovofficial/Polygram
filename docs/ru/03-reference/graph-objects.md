# Графовые объекты

**Язык:** [English](../en/03-reference/graph-objects.md) | **Русский**

## Процесс (блок/узел)

Является Источником Его Целей и Целью Его Источников.

### Контейнеры (списки)

* Типы контейнеров:
  * **Запрос** — входной Контейнер. В нём перечислено всё, что Процессу нужно для работы.
  * **Результат** — выходной Контейнер. В нём перечислено всё, что Процесс производит.
* Записи (пункты) в контейнерах: Каждая запись описывает один Показатель с названием, значением и единицей.

### Показатель

Это единица содержимого обоих Контейнеров. У Показателя есть:

* Название;
* Тип: числовой, бинарный (✓), время или процент;
* Значение: Источник данных значения: API;
* Единица измерения;
* Факт: фактическое значение рядом с плановым/запрашиваемым.

### Связь, Источники и Цели

Связь соединяет конкретный Показатель Результата с конкретным Показателем Запроса. Блок со стороны Результата называется Источником, блок со стороны Запроса называется Целью. Один и тот же Процесс играет обе роли по отношению к разным соседям:

* **Вверх по потоку** его Запрос питается Результатами других блоков. Он Цель для этих Источников.
* **Вниз по потоку** его Результат питает Запросы других блоков. Он Источник для этих Целей.

У связи есть пропускная способность: доля Результата в процентах или абсолютное значение. Поэтому один Результат можно разделить между несколькими Целями, а один Запрос можно собрать из нескольких Источников.

### Отдел (подграф)

* Визуально выглядит как просто рамка (растягивается исходя из содержащихся внутри объектов) с шапкой, там написано имя и #ID.
* Можно выделить несколько процессов и сгруппировать их в отдел.
* Экспорт и импорт отдела (подграфа) в виде файла.
* Может содержать подотделы, процессы в них, другие подотделы в подотделах и т. д.
* Статус отдела определяется по вложенным в него Процессам и отделам и визуально отображается в качестве заливки его фона.
