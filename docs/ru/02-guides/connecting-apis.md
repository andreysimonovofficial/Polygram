# Подключение API

**Язык:** [English](../en/02-guides/connecting-apis.md) | **Русский**

## Превращение внешних приложений в расширения через API

Мы превращаем приложения из интернета в расширения для Polygram. Так как Polygram — это в том числе визуализация API и вычисления, а практически любое приложение использует API.

Данные передаются мгновенно. За счёт подходящего "движка" всё идёт со скоростью трейдингового терминала.

## Оркестрация мультиагентных сетей и мониторинг сложных API-систем

Polygram позволяет orchestraтировать мультиагентные сети и мониторить сложные API-системы. Каждое внешнее приложение, использующее API, может быть превращено в расширение Polygram, что делает его частью визуального графа корпорации.
