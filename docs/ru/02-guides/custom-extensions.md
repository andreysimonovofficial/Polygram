# Кастомные расширения

**Язык:** [English](../en/02-guides/custom-extensions.md) | **Русский**

## Работа с локальными репозиториями /extensions

Расширения хранятся в отдельных локальных репозиториях (`/extensions`).

## Автономное создание и обновление модулей агентом по MCP

Принцип: Расширения хранятся в отдельных локальных репозиториях (`/extensions`).

Правило ДНК: Какие бы изменения ни вносились в расширения, они никогда не влияют на чистый код ванильного CAD.

Универсальность UI: Каждый элемент интерфейса может дополняться расширением через динамическое меню.

Агент по MCP может делать `extension create` / `extension update`. Тем самым делая те самые модули для CAD. Пользователь ощущает Себя реальным начальником. Полная автономия: Агент создает/обновляет extension и сразу подключает его к холсту без лишних вопросов.

Мыш, клавиатура и MCP используют один механизм команд.

Агент создаёт или обновляет расширение, после чего оно появляется на холсте. Ванильное ядро не меняется при добавлении расширений.
