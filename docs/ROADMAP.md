# Дорожная карта

Правило: каждый шаг запускается сам по себе и имеет проверяемый критерий готовности.
Шаги нарезаны так, чтобы помещаться в одно окно работы.

| Шаг | Что появляется | Готово, когда |
|---|---|---|
| **0–1** ✅ | Документы; ядро: сетка, ортогональные линии, команды, события, рантайм, `pg` | `test.bat`: 34 проверки зелёные; `bench.bat` на 10 000 объектов — доли секунды |
| 2 | `canvas` + `shell`: окно с GPU-холстом, терминальная тема, перетаскивание с «призраком» | Блоки встают по клеткам, линии только под 90°, 1 000 объектов держат ≤16 мс на кадр |
| 3 | `api`: MCP и HTTP поверх ядра; перенос коннекторов из MVP | Агент читает срезы и шлёт команды; значения «на лету» |
| 4 | Меню правой кнопки, палитра команд, строка статуса; разрезание остатков старого кода | Ни один файл > 1000 строк |
| 5 | **Отделы** и **Порталы** с нуля: иерархия в ядре, слои сетки, области доступа | Вложенность 3+ уровней, субагент не видит чужую область |
| 6 | **Чат**: журнал событий → сообщения-виджеты, иерархическая видимость | Лента отдела показывает события дочерних |
| 7 | **Агенты и субагенты** внутри приложения | Агент выполняет задачу в своей области |
| 8 | **`.pg` как импорт Отдела** с манифестом разрешений | Импорт ничего не делает без подтверждения прав |
| 9 | Вторая тема («гламурная», кривые Безье), уточнённые правила узких мест | Смена темы без правок холста |

## Открытые вопросы к основателю

* Правило «узкого места» (сейчас простое, см. решение 0008).
* Размер карточки и порядок строк на ней — подтвердим на шаге 2, когда увидим картинку.
