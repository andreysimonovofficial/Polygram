# Политика безопасности

**Язык:** [English](SECURITY.md) | **Русский**

## Поддерживаемые версии

| Версия | Поддержка |
|--------|-----------|
| 0.1.x  | ✅        |
| < 0.1  | ❌        |

## Сообщение об уязвимости

Если вы обнаружили уязвимость безопасности в Polygram, пожалуйста, сообщите о ней ответственно.

## Как сообщить

1. Не создавайте публичный issue на GitHub для уязвимостей безопасности.
2. Отправьте детали Unterstütze через GitHub security advisories или электронную почту maintenainer'у.
3. Включите: описание, шаги для воспроизведения, влияние и предложенное исправление (если есть).

## Что ожидать

- Подтверждение получения в течение 48 часов.
- Первичная оценка в течение 7 дней.
- Регулярные обновления о прогрессе устранения.

## Область действия

- Ядро на Rust
- GUI / холст на egui
- HTTP API и MCP-сервер
- CLI-терминал

## За пределами области действия

- Сторонние расширения в `/extensions`
- Инфраструктура, развёрнутая пользователем

## Благодарности

Исследователи безопасности, ответственно раскрывшие уязвимости, будут поблагодарены в примечаниях к выпуску (с их разрешения).
